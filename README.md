# Nepal Open University Website Redesign (UI/UX Practice Project)

## Project Overview

This project is a **UI/UX and frontend redesign practice** of the **Nepal Open University (NOU) website**.
The goal of this project is to improve the **visual design, usability, accessibility, and overall user experience**, while maintaining an academic and professional look suitable for a university website.

**Disclaimer:**
This is **not the official website** of Nepal Open University. This redesign is created **solely for educational and practice purposes**.

## Objectives
* Improve website layout and visual hierarchy
* Enhance navigation and readability
* Create a modern, clean, and responsive UI
* Apply basic UI/UX design principles
* Practice frontend development skills

## Pages & Sections Included

* **Homepage (Landing Page)**
  * Navigation bar
  * Language switcher (English / Nepali)
  * Hero section with call-to-action
* **Programs Page**
* **Admissions Page**
* **Resources Section**
* **News & Notices**
* **Footer Section**
  * Faculty contacts
  * University contact details
  * Bank account information
  * Quick links
  * Social media link
  * Feedback form

## Tools & Technologies Used
* **HTML5**
* **CSS3**
* **JavaScript**
* **Google Fonts**
* **Responsive Web Design (Flexbox / Grid)**
